## 원인
### 1. 목차 근거 요약을 확인하지 못한 것 — Gemini 무료 등급의 일시 과부하 + 모델별 하루 20회
- 실측(2026-10-25): 3.8 Flash 503(high demand), 3.7 429(하루 할당량), 3.6·3.5는 시간에 따라 200 → 503 → 429. 체인 4개가 동시에 막히면 요약 전체가 503이었다. 공급자 단위 로그 한 줄만 남아 모델별 원인을 알 수 없었다.
- 키로 쓸 수 있는 모델 목록(`/v1beta/models`)에서 대체를 찾았다. `gemini-3-flash-preview`는 별도 할당량으로 응답했다(low·high·minimal 지원). Pro 계열은 무료 할당량이 0(429)이고, 2.5 계열은 신규 사용 중단(404)이며, gemma-4-31b는 500(84초)이었다.
- 목차가 길면 앞 1,500자에서 잘려 앞 장만 남는 문제도 함께 발견했다(클린 코드 11,371자·17장 → 1~3장).

### 2. 네이버 책 API 404 — API 자체가 종료됨(복구 불가)
- 같은 키로 비교했다. `book`·`book_adv`·`shop`·`doc`만 404 `SE05 Invalid search api`이고, `blog`·`news`·`encyc`·`webkr`·`kin`·`image`는 200이다.
- 보도(토큰포스트 등)의 "쇼핑·책·전문자료 검색 API 2026-07-31 종료, 이후 기존 키 호출 차단"과 정확히 일치한다. 같은 보도에 따르면 2026-09-07 시행 개정 약관은 검색 API를 "네이버 검색 결과를 그대로 보여주는 목적"으로만 허용하고, AI 학습·요약 활용을 금지한다. 남은 네이버 검색 API를 책 정보 대체로 쓰는 것도 맞지 않는다.
