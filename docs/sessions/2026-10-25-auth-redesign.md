## 디자인 계획 — "책갈피를 꽂아 둔 자리"

- 색(앱 아이콘 Ember Frost에서): 히어로 Dusk Ink `#1D2142` + 왼쪽 아래 잉걸불 빛 `#C8643A`(약 30%), 은행 금빛 `#E9A73B`은 책갈피 한 곳에만, 히어로 글자 `#F4F1EA`. 폼 쪽은 앱 테마 변수(`--bg-primary`·`--bg-card`·`--text-*`·`--border-color`, 다크 모드 포함), 버튼·링크는 강조색 `--brand-600`.
- 글꼴: 히어로 문장만 고운바탕(`--font-book`), 나머지는 Pretendard.
- 기억에 남을 한 가지: 히어로 위에서 내려와 문장 바로 위에서 멈추는 금빛 책갈피("읽던 자리"). 첫 로딩에 한 번만 내려오고, 동작 줄이기 설정이면 멈춰 있다.
- 걷어 낼 것(생성형 기본값): 그라데이션 덩어리, 떠다니는 사각형, 가짜 목업 카드, 그라데이션 버튼, 버튼의 '→'·🚀, 폼을 감싼 그림자 카드.
- 구조: 공용 `AuthShell`(데스크톱 왼쪽 히어로 / 모바일 위쪽 낮은 띠) + 폼 한 번만 렌더링. 공용 입력·버튼은 `authUi.tsx`.

## 구현·검증

- 공용: `src/app/components/auth/AuthShell.tsx`(히어로·책갈피·폼 자리), `authUi.tsx`(입력칸·버튼·Google 버튼·구분선·머리말). 화면은 폼을 한 번만 렌더링한다.
- 다크 모드: 폼 쪽은 테마 변수. 검사 중 `#DC2626` 오류 글자가 다크 카드에서 2.9:1이라 `--text-danger`(다크 `#F87171`)를 추가했고, 링크는 `--text-accent`(다크에서 brand-300)로.
- 스크린샷 비평에서 고친 것: 약관 체크박스가 전역 터치 규칙(버튼 min-height 44px) 때문에 20×46 막대로 보였다(원래 화면에도 있던 문제) → 버튼을 44px 터치 영역으로, 20px 상자는 안쪽에.
- axe-core 4.10(WCAG 2 A/AA, 개발 전용 미리보기 바 제외): 처음엔 진행 막대 이름 없음 1건 → `aria-label="가입 단계"` → 로그인(모바일·데스크톱)·가입 4단계 모두 라이트·다크 위반 0건.
- **55차 회귀 발견·수정**: `npm run dev`가 `[pwa] precache에 index.html이 없습니다` 오류 화면으로 막혔다. 개발 서버 매니페스트에는 index.html이 없는데 변환이 항상 오류를 냈다. `precacheIndexAsRoot({ strict: command === 'build' })` — 배포 빌드만 엄격(테스트 4개). 운영·CI 빌드는 index.html이 있어 영향 없었다.
- 회귀 테스트 `src/app/pages/__tests__/AuthPages.test.tsx`: 입력칸·h1·form이 하나씩, 빈 비밀번호 제출 시 `aria-invalid`, 가입 진행 막대 1/4, 약관 전 [다음] 비활성.
- 온보딩(`/onboarding`)은 요청 범위 밖이라 그대로 두었다(흰 바탕·알록달록 일러스트·그라데이션 버튼). 필요하면 같은 원칙으로 맞출 수 있다.
