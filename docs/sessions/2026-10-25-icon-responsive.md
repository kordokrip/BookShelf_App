## 1. 반응형 점검

## 2. 앱 아이콘 '가을→겨울'

- 도구 선택: 아이콘은 `design/icons/*.svg` 벡터 마스터 → `scripts/assets/generate-icons.mjs`로 모든 크기를 만드는 구조라, AI 이미지 생성(래스터)보다 벡터 직접 설계가 맞다. `canvas-design` 스킬(디자인 철학 → 작품)로 원칙과 마스터를 만들고, `design-critique` 스킬로 홈 화면·파비콘·maskable·링크 미리보기 시트를 평가해 고쳤다.
- 원칙 `design/icons/season-philosophy.md`("Ember Frost"): 온도가 곧 시간, 구조는 그대로·대기만 바뀜, 잎 하나·눈 한 줌, 작아지면 덜어 낸다.
- 결과
  - 브랜드 마크 도형은 유지(앱 안 `AppLogo`와 같은 모양). 하늘이 잉걸불 → 녹슨 주홍 → 자두빛 → 겨울 남색으로 식고, 책·선반 종이색도 같은 축.
  - 왼쪽 하늘에 은행잎(부채꼴·가운데 갈림), 오른쪽 책 두 권과 선반 끝에 쌓인 눈, 가지 달린 눈 결정 하나. 금빛 책갈피는 잎과 같은 금색.
  - 16~48px 마스터는 잎·눈송이를 덜고 오른쪽 책을 진한 서리색으로 해 눈이 보이게 했다(비평에서 32px에 눈이 안 보인다는 지적 반영).
  - maskable은 흰 글리프 대신 마스터 그림(`id="art"`)을 72%로 줄여 안전 영역에 넣는다(가장 먼 점 반지름 약 376/410px).
  - 바로가기 4종·링크 미리보기 배경도 같은 하늘. iOS 스플래시(단색 글리프)·앱 안 로고(강조색)는 그대로.
- 아이콘 파일은 `max-age=0, must-revalidate` + 서비스 워커 precache 리비전이라 다음 업데이트에 반영된다. iOS 홈 화면 아이콘만 다시 추가해야 바뀐다.

## 4. 발견한 문제(미수정, 기존부터)

- **서비스 워커 precache가 비면 앱이 열리지 않는다.** 서비스 워커는 등록된 채 Cache Storage만 지워진 상태(브라우저 저장소 정리·확장 프로그램 등)에서 모든 화면 이동이 `net::ERR_FAILED`. 새 컨텍스트에서 재현했다(캐시 1개 삭제 → `/login`·`/wishlist`·`/` 모두 실패).
- 원인 추정: Workbox `navigateFallback`이 precache의 `index.html`을 찾지 못하면 네트워크로 `/index.html`을 받는데, Workers Assets가 `/index.html` → `/`로 307 리다이렉트한다(`curl -sI …/index.html`). 리다이렉트된 응답은 화면 이동 응답으로 쓸 수 없어 실패한다.
- 고칠 방향(ADR-001 서비스 워커 갱신 전략과 함께 검토): 화면 이동 폴백을 precache 실패 시 네트워크 `/`로 받도록(NetworkFirst 또는 `navigateFallback`을 리다이렉트 없는 URL로), 또는 Workers Assets의 `/index.html` 리다이렉트를 끈다. 운영 영향 범위가 서비스 워커 전체라 사용자 확인 후 진행한다.
