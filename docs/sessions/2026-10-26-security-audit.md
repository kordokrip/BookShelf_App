### 이상 없음(확인함)
- JWT HS256 고정 검증·만료·휴면 차단, PBKDF2 10만 회 + 상수 시간 비교, 로그인 IP·계정 단위 한도, rate limit IP는 위조 불가한 `cf-connecting-ip`.
- 관리자 경로 12개 모두 인증 + 관리자 검사, `seed-admins`도 관리자만.
- SQL: 전부 바인딩, 정렬 열·방향 허용 목록, FTS 질의 이스케이프 — 인젝션 없음.
- 책·노트·세션·컬렉션·알림 수정·삭제는 모두 본인 소유 확인. 노트·세션·컬렉션은 책 소유도 확인.
- XSS 싱크(`dangerouslySetInnerHTML`·`innerHTML`) 없음, 오류 응답에 내부 정보 없음, LLM 출력은 텍스트로만 렌더.
- WebSocket 접속 시 토큰·회원 확인, `X-User-Id`는 Worker가 덮어씀(위조 불가).

### 남긴 위험(기능 보호 때문에 이번에 바꾸지 않음)
- **OAuth `state`(로그인 CSRF)**: iOS 홈 화면 앱에서 구글 로그인 중 저장소가 갈릴 수 있어, 쿠키·스토리지 기반 state는 구글 로그인을 깨뜨릴 위험. 영향은 "공격자 계정으로 로그인됨"(화면에 공격자 이름이 보임) 수준. 실기기 확인 뒤 별도 진행 권장.
- **이메일 가입 무인증**: 이메일·비밀번호 가입은 메일 인증이 없고 `ALLOWED_EMAILS` 게이트도 구글 경로에만 적용된다. 가입 정책(공개/초대제) 결정 사항.
- **토큰 저장 위치**: 액세스·리프레시 토큰이 `localStorage`. HttpOnly 쿠키 전환은 큰 구조 변경 — CSP로 XSS 경로를 먼저 막았다.
- **개발 도구 취약점**: vite 개발 서버·wrangler CLI·sharp·happy-dom 등(운영 미포함). wrangler는 workers-types 메이저 연동이라 별도 업그레이드.
